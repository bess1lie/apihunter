# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ |
| 0.1.x   | ⚠️ (upgrade recommended) |

## Reporting a Vulnerability

apihunter is **detection-only** — no payloads, no exploitation. If you find a vuln in the tool itself, report privately.

**Do not** open a public issue for security vulns.

Contact: **bess1iework@gmail.com** — response within 48h.

Scope: all requests gated by `scope.yaml` — out-of-scope usage is not supported. See `docs/scope.md` and `scope.example.yaml`.

### Disclosure

- We acknowledge receipt within 48h.
- We aim to publish a fix + GHSA advisory within 14 days.
- Please allow 90 days before public disclosure.
